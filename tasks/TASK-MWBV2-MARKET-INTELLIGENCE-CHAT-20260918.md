# TASK-MWBV2-MARKET-INTELLIGENCE-CHAT-20260918

任务状态、读取清单与验证结果：[Context Manifest](../tasks-context-manifests/TASK-MWBV2-MARKET-INTELLIGENCE-CHAT-20260918.json)。

## 目标

将市场情报预告卡开放为简洁的已登录只读对话页，供用户录入本人公共数据凭证后以自然语言查询素材、播放视频及查看单条人气趋势。

## 批准方案

用户于本轮明确要求最简洁的自然语言验证对话框，随后选择稍后在页面录入 Token。按 [Solution Design](../docs/Solution%20Design.md) 的“市场情报最简只读对话”执行；数据接口合同由当前数据契约承接，指定开发方案资料仅作 reference_only。

## 范围

市场情报注册与入口、独立对话页面、受控只读客户端、本人连接凭据存储、同源视频代理、针对性回归与当前合同文档。正式服务按既有 main release 流程部署；既存模板改名保持原样。

## 非目标

不修改投放创建业务链；不调用投放平台写入；不修改公共电脑服务/防火墙；不做排名、覆盖率聚合、跨素材比较或模型视频理解；不读取用户尚未交接的凭证，不声称已完成真实带凭证验收。

## 验收

- AC-01: 新 Agent 可进入简洁对话页；支持列表、选中素材详情/视频、单条趋势及清楚的未支持提示，投放创建入口保持可用。
- AC-02: 连接与数据按登录用户隔离；配置防跨站、Token 不回显，私网地址/重定向/响应投影/错误及视频 Range 边界有隔离回归。
- AC-03: 实测公共电脑 TCP 可达、无凭证 401；浏览器验证桌面/窄屏对话和模拟视频/趋势；真实带凭证验证明确留给用户录入后进行。
- AC-04: 项目合同检查、针对性回归、main 正常提交/推送和 release 发布通过，远端 SHA 可核对。

## 停止条件

出现越权、凭证泄漏、需平台写入或现有投放创建回归失败时停止对应发布；接口缺失能力明确报告，真实凭证未录入不阻止开发验收，但禁止虚构真实查询成功。

## 交付说明

验收及发布证据存于 Manifest。任务完成表示页面和受控只读接入实现可供验证，不等于公共电脑真实素材已在本机带凭证查询或播放成功。模板原路径已被用户删除，使用 base_revision 中原模板内容创建本任务，不恢复或提交既存模板变更。

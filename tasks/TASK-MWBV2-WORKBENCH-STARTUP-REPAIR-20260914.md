# TASK-MWBV2-WORKBENCH-STARTUP-REPAIR-20260914

任务状态、读取清单与验证结果：[Context Manifest](../tasks-context-manifests/TASK-MWBV2-WORKBENCH-STARTUP-REPAIR-20260914.json)。

## 目标

修复固定 release 无法读取共享乾坤凭据的问题，并让投放创建页以单一对话启动卡片和即时启动侧栏呈现真实启动状态。

## 批准方案

用户批准“恢复凭据读取，收拢启动入口”：发布运行时显式使用共享凭据文件；完整 Intake 仅在最新对话下显示一个启动卡片；启动后立即展示真实请求阶段，只有取得 Job 才显示服务端七节点进度。

## 范围

允许修改工作台发布环境、乾坤凭据路径解析、投放创建前端及相应回归测试和当前文档。所有平台请求保持既有 readonly/Plan 确认链。

## 非目标

不修改数据库结构、API、Node/Gate、账户预检规则或任何平台写入；不复制、记录或输出凭据内容。

## 验收

- AC-01: 固定 release 与开发目录均解析到同一共享乾坤凭据文件，发布检查在文件缺失时失败。
- AC-02: 完整自然语言或 JSON Intake 只显示一个有效启动卡片；输入变化立即失效，点击期间按钮显示“启动中…”。
- AC-03: 启动即时显示侧栏；预检、建 Job、运行及失败只展示真实阶段，Job 存在时显示服务端节点进度。
- AC-04: 浏览器回归覆盖启动点击、重复点击、输入失效、失败反馈和窄屏；现有工作台与项目检查通过。
- AC-05: 新 release 在公司模式启动，静态页面和共享凭据路径均由实际运行版本核验。

## 停止条件

若共享凭据文件不存在或格式无效、发布重载无法自动恢复、或修复需要扩大账户权限/平台写入，则停止并报告。

# TASK-MWBV2-AGENT-HUB-SHELL-20260910

任务状态、读取清单与验证结果：[Context Manifest](../tasks-context-manifests/TASK-MWBV2-AGENT-HUB-SHELL-20260910.json)。

## 目标

将登录后的单一投放工作台升级为数字员工广场和投放创建 Agent 壳层，同时保持现有确定性 Workflow 的行为、地址语义与账户隔离不变。

## 批准方案

实施用户于 2026-09-10 批准的“投放创建 Agent P0：多 Agent 工作台与可配置 LLM 最小闭环”中的 Task 1：采用服务端 Agent 注册表、`/agents` 广场和 `/agents/launch-creation` 工作区；对话状态继续挂载既有投放 Workflow。用户菜单收纳改密、退出及管理员用户管理，并将自主改密改为可取消弹窗；首次登录强制改密保持不可取消。此 Task 不引入模型配置或 LLM 调用，相关安全方案在后续独立 Task 实施。

## 范围

- 新增安全的投放创建 Agent 注册表与公开目录接口。
- 增加数字员工广场、三栏工作区壳层、模块地址和小屏折叠体验。
- 兼容既有 Case/Job 链接并将旧根路径链接导向新工作区。
- 迁移现有顶部操作到可收起的用户菜单，保留认证和 Workflow 逻辑。
- 同步 Solution Design 与当前逻辑图中壳层边界说明。

## 非目标

- 不创建模型配置表、凭据库、LLM Adapter 或任何外部模型调用。
- 不改变 Gate、Plan、确认、运行时写入策略、平台适配器或数据库业务事实。
- 不实现记忆、知识库、技能、数据统计的业务详情；本 Task 仅提供可导航壳层。
- 不新增定时任务、知识上传、向量库、技能编辑、批量/多账户投放或预算出价推断。

## 验收

- AC-01: `/agents`、`/agents/launch-creation`、公开 Agent 目录接口与旧 Case/Job 地址兼容可用，且接口不泄露账户或凭据数据。
- AC-02: 广场、工作区三栏、模块导航、响应式折叠、可收起用户菜单及可取消自主改密弹窗符合 P0 壳层要求；首次改密仍不可取消。
- AC-03: 登录、用户角色隔离、现有对话/确认/进度 Workflow 以及历史 Case/Job 恢复保持可用。
- AC-04: 相关自动化检查通过，文档准确记录壳层不参与 Workflow 决策的边界。

## 停止条件

- 需要改变确定性 Gate、Plan、确认、平台写入权限或数据库运行事实时，停止并转入独立批准 Task。
- 需要保存或展示凭据、原始对话、其他用户数据，或访问范围超出当前用户授权时，停止并报告。
- 新地址无法兼容现有 Case/Job 地址语义或回归检查发现隔离风险时，停止并先修复。

## 交付说明

已交付数字员工广场、投放创建 Agent 三栏壳层、公开目录接口、规范地址兼容、用户菜单和可取消自主改密弹窗。现有对话与固定 Workflow 保持原链路；模型配置、LLM 解析与其余模块详情留给后续独立 Task。状态和逐项验证仅维护在 Manifest。

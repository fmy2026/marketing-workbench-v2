# TASK-MWBV2-MI-SEARCH-REPORT-20260920

任务状态、读取清单与验证结果：[Context Manifest](../tasks-context-manifests/TASK-MWBV2-MI-SEARCH-REPORT-20260920.json)。

## 目标

将市场情报工作台落地为“查找素材 → 生成 HTML 月报”的只读闭环：用户可用自然语言与可见筛选浏览公共电脑素材，随后以当前月份与研究对象生成一份可编辑、可离线打开的已采集样本月报。

## 批准方案

采用用户确认的简洁视觉基准：桌面素材网格四列、手机两列、每页八条，底部固定输入框；月报仅突出编辑摘要和下载 HTML。页面壳层沿用投放执行的顶部栏、当前用户菜单与可收起六模块导航，默认“对话状态”只保留自然语言输入。首版使用已采集样本月报，不等待全量月度汇总。用户已批准“游戏与日期的受控查询、服务端重新核验样本、模型仅解释脱敏证据、单文件 HTML 导出”，详见 [Solution Design](../docs/Solution%20Design.md) 与当前逻辑图的数据边界。

## 范围

- 在市场情报 Agent 中实现结构化素材查询、共享筛选状态、视频网格、分页、详情播放与按月样本核验。
- 启用按“用户 × 市场情报 Agent”隔离的模型配置与受控模型调用，模型只解析查询意图或总结服务端证据。
- 实现固定结构的样本月报、摘要编辑和单文件 HTML 下载；不保存报告或对话。
- 更新市场情报的流程、数据合同、部署说明与方案索引，并保留脱敏验证证据。

## 非目标

- 不新增公共电脑采集任务、数据库表、情报历史、长期记忆或自动定时报告。
- 不实现跨素材比较、全量市场排名、ROI、投放建议、Case、Plan 或任何平台写入。
- 不将 Token、原始响应、外部视频地址、模型 API Key 或用户原始对话写入项目、报告或证据。

## 验收

- AC-01: 素材查询页符合已批准的简洁布局，桌面四列、手机两列、每页八条，并保留键盘可用的查询、分页和详情入口。
- AC-02: 自然语言和页面筛选共用游戏、月份、分页状态；结果、空集、失败与视频播放按真实只读合同呈现，不混淆页内数量和服务端总数。
- AC-03: 月报只纳入在目标月份具有有效观察证据的至多三十条样本，正确处理零值、缺失、无上月数据与部分查询失败。
- AC-04: 市场情报模型配置按用户隔离；模型失败、非法输出、无依据结论与素材中的指令不会进入有效查询或报告。
- AC-05: 人工编辑后的报告可预览并下载为不含外部依赖、凭据和可执行用户输入的单文件 HTML。
- AC-06: 现有投放执行、旧入口、市场情报连接隔离和视频代理回归通过。
- AC-07: 留存真实公共电脑查询、MP4/WebM 播放、模型、月报导出及实际页面的脱敏验收证据；若真实条件不可用，如实保留缺口。

## 停止条件

- 公共电脑无法证明月份归属、稳定分页或可用素材字段时，停止相关真实功能的完成声明，并保留具体合同缺口。
- 未经授权的连接、模型凭证、公共电脑采集或任何平台写入均不执行。
- 实现需要扩大到比较、持久化情报或投放策略时，停止并建立独立方案。

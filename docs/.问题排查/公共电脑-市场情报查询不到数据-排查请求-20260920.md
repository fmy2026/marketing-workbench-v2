# 市场情报无法连接公共电脑：排查请求

## 当前现象

- 工作台：市场情报 Agent。
- 操作：发送“查看当前已采集的游戏和素材”。
- 页面结果：**“暂时无法连接公共电脑。”**
- 影响：无法读取候选游戏和素材，后续的素材查询、视频、趋势与 HTML 月报均无法进行。

工作台已保存本人数据连接，但“已保存”不代表服务在线；本次错误发生在工作台向公共电脑发起只读请求时。

## 已知历史记录（请与当前状态对照）

- 2026-09-18 曾记录公共电脑地址为 `http://192.168.16.136:8787`。
- 当时从工作台侧探测：TCP 可连通；未携带鉴权访问 `GET /api/v1/health` 返回 HTTP `401`。这只能证明当时服务可达且要求鉴权，**不证明今天地址、服务或 Token 仍有效**。
- 当前页面不是“请先配置数据连接”，而是“暂时无法连接公共电脑”。这表示该登录用户仍有连接记录，工作台已尝试使用其保存的地址和 Token 请求公共电脑，但本次请求未成功。
- Token 不保存在文档、Git 或数据库中。它仅在工作台机器上按登录用户保存；请勿要求或在回复中发送 Token。若需更新，请通过既有安全交接方式重新签发。

## 请公共电脑优先检查

1. **服务是否运行并监听公司内网地址**
   - 公共电脑上的市场情报服务是否正在运行。
   - 服务端口是否仍为约定端口（当前工作台按 `http(s)://内网 IPv4:端口` 连接）。
   - 不应只监听 `127.0.0.1`；工作台所在机器需要通过公司局域网访问。
   - 公共电脑防火墙、系统安全策略或公司网络是否拦截该端口。

2. **地址是否变化**
   - 请确认公共电脑当前公司 Wi‑Fi 的 IPv4 和服务端口，并特别核对是否仍为历史地址 `192.168.16.136:8787`。
   - 若 IP 或端口变了，请提供新的 `http(s)://IPv4:端口`，我会在工作台“数据连接”更新地址。

3. **健康检查和鉴权是否可用**
   - `GET /api/v1/health` 应在携带有效 Bearer Token 时返回成功 JSON。
   - 当前 Token 是否仍有效、是否被轮换或服务端改为其他鉴权方式。
   - 请勿在回复中发送 Token；只需说明“当前 Token 有效 / 已失效 / 需要重新签发”。

4. **素材列表接口是否能返回数据**
   - `GET /api/v1/assets?page=1` 应能返回当前候选素材。
   - 请确认响应外层仍是成功信封，且 `data` 是数组；请提供脱敏后的素材数量、游戏名称示例和字段名即可。
   - 工作台不会内置游戏名；只有该接口返回的真实游戏名称才会显示和继续查询。

## 工作台依赖的最小只读合同

| 能力 | 公共电脑接口 | 需要确认 |
| --- | --- | --- |
| 连接验证 | `GET /api/v1/health` | 可达、鉴权成功、返回 JSON |
| 发现素材 | `GET /api/v1/assets?page=1` | `data` 为素材数组，含稳定 ID、标题、游戏名称；可提供 `meta` |
| 素材详情 | `GET /api/v1/assets/{id}` | `data.asset`、允许的标签与脚本文本 |

| 视频播放 | `GET/HEAD /api/v1/files/{id}` | MP4 或 WebM；支持单段 Range |

## 判断标准

- 若健康检查不可达：优先修复服务进程、监听地址、端口或网络策略。
- 若健康检查可达但鉴权失败：重新签发或更新工作台用户自己的 Token。
- 若健康检查成功但素材列表为空或格式变化：请提供脱敏合同样例，以便核对公共电脑接口与工作台投影。
- 只有公共电脑可读接口恢复后，工作台才会显示真实游戏和素材；不应以示例数据替代。

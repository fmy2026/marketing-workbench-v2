## 数据边界

只记录端点路径、字段名、字段存在性、脱敏状态、hash 和必要 ID。禁止记录认证值、完整 URL、host、原始请求、原始响应、Cookie、完整 callback URL、完整点击监测 URL。

`os=3` 在 v2 中按乾坤“小游戏”技术系统类型理解；它不能单独决定业务媒体归属。最终语义由 `platform / L2 媒体 / L3 media_id / monitor_api / channel` 共同决定：当前 `oceanengine + toutiao_wxgame + dymini3k` 仍按 Byte 小游戏投放链路处理；广点通相关媒体或监测 API 才进入业务微信小游戏口径。

有效实现口径：

- 旧参考文档将 `server_callback_type`、`server_callback_data_types` 标为可选，但 2026-08-26 技术确认当前真实创建环境中二者必填。
- `oceanengine_3_byte_mini_game + JSZC` 的 v2 创建合同已按该口径持久化到 `mwb.game_route_defaults.raw_defaults.monitor_provision`。
- 编译器必须输出：

```text
server_callback_type=2
server_callback_data_types[]=active
server_callback_data_types[]=register
server_callback_data_types[]=success_order
```

- 缺少上述任一字段时，创建前必须阻断并返回 `callback_contract_missing`。

当前 `monitor:ensure` 必须保持阻断：

```text
qiankun_monitor_config_unverified
```

## 结构判断

当前 v2 已经把最关键的运行真值分开了：

- job / draft：`mwb.launch_jobs`、`mwb.launch_drafts`
- 项目名占用：`mwb.project_name_reservations`
- 平台 app：`mwb.game_platform_apps`
- 账户资源：`mwb.account_resources`
- 游戏素材主档：`mwb.game_assets`
- 物料包选择：`mwb.material_packs`、`mwb.material_pack_items`
- 触点 URL：`mwb.account_touchpoints`
- 平台动作审计：`mwb.platform_actions`

但还有 5 类信息不应长期停留在当前形态：

1. 出价、预算、ROI、排期、基础定向应从 `game_route_defaults` 下沉为账户级投放策略 profile。
2. 精确排期不能只保留 `schedule_time_digest`，应保存可逆结构。
3. 抖音号身份不应挂在 `avatar` metadata 下，建议新增账户身份表。
4. 标题、卖点、CTA、AIGC、图片素材、组件设置应进入 creative profile。
5. 备用网页落地页和组件素材应独立建 landing/component profile。
